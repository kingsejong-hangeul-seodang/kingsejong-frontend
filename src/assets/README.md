# 에셋

- `images/`: 로고·배경·이미지
- `icons/`: SVG 아이콘
- `fonts/`: 사용 권한을 확인한 폰트

컴포넌트에서는 `import logo from '@/assets/images/logo.svg'`처럼 불러옵니다.
Foundation의 색상·여백·모서리·글자 규격은 `src/styles/`에서 관리합니다.
토큰 사용법과 폰트 적용 상태는 [디자인 시스템 문서](../../docs/design-system.md)를 참고하세요.
이 페이지에는 이미지·아이콘·폰트 파일이 없어 바이너리 에셋은 추가하지 않았습니다.
폰트 이름은 설정했으며 해당 글꼴이 설치되지 않은 환경에서는 대체 글꼴로 표시됩니다.
외부에 고정 URL로 제공해야 하는 파일만 `public/`에 넣습니다.
