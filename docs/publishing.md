# Screens v2 퍼블리싱

원본: [Figma Screens v2](https://www.figma.com/design/T4iKsOzvLK6QEnVRCeakTS?node-id=65-469).
33개 프레임을 React + TypeScript + CSS Modules로 구현했습니다. 원본의 820 × 1180
태블릿 크기를 기준으로 하고, 819px·580px에서 여백과 카드 배치를 조정합니다.
모바일의 긴 원고지는 영역 안에서 가로로 스크롤합니다.

컴퓨터에서는 820 × 1180 크기의 아이패드 화면을 창 높이에 맞춰 비율 그대로
축소해 표시합니다. 화면 안에서 스크롤하며 하단 메뉴와 버튼은 아이패드 화면
하단에 고정됩니다. 터치 기기와 좁은 창에서는 해당 기기 화면을 그대로 사용합니다.
필기·레벨 테스트는 검은 예시 글씨 없이 빈 칸에서 시작합니다. 초보 단계의 회색
따라쓰기 글자와 설명 문구는 유지합니다.

## 실행과 확인

```sh
npm ci
npm run dev
npm run check
npm run check:assets
```

해시 경로를 사용하므로 정적 서버에 별도 rewrite 설정이 필요하지 않습니다.
기본 진입 화면은 `/#/lang`이며, 개발 서버 주소 뒤에 아래 경로를 붙이면
각 화면을 직접 확인할 수 있습니다.

| ----------- | --------------------------------------------------------------------------- |
| 시작        | `/#/lang`, `/#/login`, `/#/experience`, `/#/stage-select`                   |
| 레벨 테스트 | `/#/leveltest-1`, `/#/leveltest-2`, `/#/leveltest-3`, `/#/leveltest-result` |
| 취향        | `/#/mode-select`, `/#/taste`                                                |

## 구조

- `src/app`: 경로 목록, 지연 로딩, 선택한 난이도·모드·언어·가수 상태.
- `src/layouts`: 공통 본문·로딩·화면 제목·포커스·알림.
- `src/components/ui`: 상단바, 하단 메뉴, 난이도 선택, 공통 버튼 동작.
- `src/components/SejongGuide`: 원본 캐릭터 표시.
- `src/components/WritingBoard`: Pointer Events 기반 필기, 지우기, 작성한 칸 수.
- `src/features/*/screens`: 기능별 프레임. `data-node-id`는 원본 레이어 대조용입니다.
- `src/styles/screens.module.css`: 여러 화면에서 공유하는 원본 배치 규칙.
- `src/styles/global.css`: 초기화, 선택 상태, 고정 하단 영역, 반응형 규칙.
- `public/assets/figma`: 원본 PNG·SVG 150개. 임시 Figma 주소를 런타임에 사용하지 않습니다.

공통 컴포넌트와 Figma 대응표, 원고지 사용 예시는 [컴포넌트 안내](components.md)를
참고하세요. 반복 UI는 Figma Components 페이지를 기준으로 교체했습니다.

색상·간격·글꼴 이름은 기존 Foundation 토큰을 재사용합니다. 기존 설정과 동일하게
Noto Sans KR와 Nanum Pen은 설치된 글꼴을 우선 사용하고, 없으면 시스템 글꼴로
표시합니다. 동국체 제목·학습 가이드 글자는 Figma SVG를 사용합니다.

## 현재 연결 범위

이 작업은 퍼블리싱과 UI 동작 구현입니다. 로그인은 입력 형식만 검사하며 인증
서버를 호출하지 않습니다. 예시 코드 `SEJONG-07`로 화면을 진행할 수 있습니다.
로그인 코드와 필기 데이터는 localStorage에 저장하지 않습니다. 난이도·모드·언어·가수
선택과 EXP를 브라우저에 보관하며, 로그아웃 시 제거합니다.

필기와 지우기는 실제로 동작합니다. 제출 시 각 칸의 캔버스 이미지를 메모리에 보관하고,
결과와 정답 비교의 ‘내가 쓴 글’ 영역에 같은 필기를 표시합니다. 제출 내용이 없으면
안내를 표시하며, 예시 글씨나 임의의 채점 결과를 대신 표시하지 않습니다. 필기 이미지는
새로고침·로그아웃 시 사라집니다. 정답 글씨·쓰기 기록·레벨 테스트 추천은
Figma의 예시 데이터입니다. 채점·획순 인식·영상 재생·학습 기록 저장·번역 API는
연결하지 않았습니다. 언어 선택은 선택 상태만 반영합니다. 실제 콘텐츠 API가
준비되면 콘텐츠 카드와 학습 화면에 콘텐츠 ID를 전달하고, 결과 화면을 채점 응답으로
연결해야 합니다. 도감 상세는 원본에 있는 ㄷ·ㅏ 두 화면을 구현했고, 나머지 자모는
안내를 표시합니다. 비교 화면의 다시 보기는 정답 칸을 순서대로 강조하는 UI입니다.

마이페이지의 성장 이미지는 EXP 기준(0·300·800·1,500·3,000)에 따라 공개됩니다.
미달성 단계는 캐릭터를 검은 실루엣으로 가리고 가운데 `?`를 표시합니다.
이름과 필요 EXP는 유지하며, 달성 시 원본 이미지로 공개됩니다.
현재 레벨업 예시 화면에서 나가면 300 EXP 이상으로 반영하며, 실제 EXP 적립은
향후 학습 API와 연결해야 합니다.

## 검증

- TypeScript·ESLint·Prettier·프로덕션 빌드.
- 로컬 에셋 파일과 33개 경로를 `check:assets`로 확인.
- 브라우저에서 820 × 1180과 390 × 844 크기로 전체 화면 점검.
- 로그인 빈 값, 선택 상태 변경, 메뉴 이동, 필기·지우기, 결과·비교 이동 확인.
