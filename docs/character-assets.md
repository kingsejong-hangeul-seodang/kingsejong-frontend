# 성장 캐릭터 이미지

마이페이지 성장 목록은 단계별 원래 캐릭터를 사용하고, 잠긴 단계에 검은 실루엣과 물음표를 표시한다. 물음표 위치는 각 캐릭터 중심 좌표로 지정한다.

Figma에서 받은 킹세종 PNG는 왼쪽 용과 불꽃 외곽이 원본부터 잘려 있었고, 대제학 PNG에는 오른쪽에 다른 이미지 조각이 포함되어 있었다. 내장 이미지 편집 도구로 복원한 투명 PNG를 사용한다. 사용하지 않는 원본은 배포 에셋에서 제외했다.

| 원본                            | 화면에서 사용하는 복원본                            |
| ------------------------------- | --------------------------------------------------- |
| `public/assets/figma/bacab.png` | `public/assets/characters/king-sejong-complete.png` |
| `public/assets/figma/54151.png` | `public/assets/characters/daejaehak-complete.png`   |

편집 프롬프트: 기존 얼굴·자세·의상·그림체를 유지하고 킹세종의 잘린 용과 불꽃 외곽만 복원한다. 대제학의 오른쪽에 떨어져 있는 다른 불꽃 조각만 제거한다. 캐릭터와 자신의 불꽃 전체를 유지하고 모든 방향에 투명 여백을 둔다. 텍스트나 물음표는 이미지에 넣지 않는다.
